# VLP Maths Tools (Primary) — version 20.0

The Maths Repository, Quadrant Check and Daily Review, as a web page. This folder holds the app only: no VLP lessons,
questions, programs or slides. Each school keeps those in its own Teaching and Learning folder:

    Teaching and Learning › Whole School › VLP Resources
        VLP Maths data - Primary.zip
        Lesson slides     › VLP Maths Slides - Foundation.zip, VLP Maths Slides - Level 1.zip … Level 6.zip
        Retrieval slides  › VLP Maths Retrieval Slides - Foundation.zip, … Level 7.zip

## Put it on GitHub Pages (once)

1. Make a repository on GitHub (for example `vlp-maths-tools`). It can be public: nothing in it is VLP content.
2. Upload the files in this folder: `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `README.md`.
3. In the repository: **Settings › Pages › Build and deployment**: Source **Deploy from a branch**, branch **main**, folder **/ (root)**. Save.
4. After a minute the address shows at the top of that page, e.g. `https://<your account>.github.io/vlp-maths-tools/`. Give teachers that address.

## Push out an update

Upload the new `index.html` (and `sw.js` if it changed) over the old ones. Teachers get it the next time they open the
tools; anyone with the tools open sees "Version … is ready · Reload now" within half an hour.

When the VLP content changes, give schools the new file(s) for their VLP Resources folder instead.

## Teachers

Open the address in Microsoft Edge or Google Chrome, choose **Connect the Teaching and Learning folder**, and pick the
Teaching and Learning folder that OneDrive syncs from the school's SharePoint. Other browsers (iPad, Safari, Firefox):
**Choose the files instead**.

The page also works opened straight from the file (index.html), with the same folder.
